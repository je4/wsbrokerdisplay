# Display Coordinator Package (`pkg/display`)

The `pkg/display` package coordinates incoming WSBroker WebSocket events directly with the underlying Chromium browser instance. It functions as the display-side service component that hosts remote control capabilities (navigation, URL inspection, and screenshot generation) via `wsbrokerclient`.

---

## Key Responsibilities

1. **Direct WSBroker Integration**: Works directly with `github.com/je4/wsbrokerclient/pkg/client` to subscribe to `event.TypeMessage` events, decode `CommandMessage` payloads, and route actions to browser operations.
2. **Loop Prevention**: Automatically ignores events generated by the display client itself to prevent feedback loops.
3. **Execution Safety**: Executes browser operations with configurable context timeouts (`WithTimeout`) and handles errors gracefully without crashing the service.
4. **Structured Request-Reply Dispatching**: Transmits typed response envelopes (`navigate_response`, `geturl_response`) and binary screenshot file events (`event.TypeFile`) back to the request source, preserving correlation tokens.

---

## Interfaces

To facilitate decoupling and unit testing, `pkg/display` interacts with external components through interfaces:

### `BrowserInterface`
```go
type BrowserInterface interface {
    Navigate(ctx context.Context, targetURL string) error
    NavigateWait(ctx context.Context, targetURL string, waitSelector string) error
    GetURL(ctx context.Context) (string, error)
    Screenshot(ctx context.Context, opts browser.ScreenshotOptions) ([]byte, string, error)
}
```

### `ClientInterface`
```go
type ClientInterface interface {
    ClientName() string
    OnMessage(handler func(evt *event.Event)) client.UnsubscribeFunc
    Send(ctx context.Context, evt *event.Event) error
}
```
*Note: `*client.Client` from `github.com/je4/wsbrokerclient/pkg/client` directly satisfies `ClientInterface`.*

## Supported Commands

### 1. `navigate`
- **Action**: Loads a target URL into the browser viewport.
- **Payload**:
  ```json
  {
    "action": "navigate",
    "url": "https://example.org",
    "selector": "#content"
  }
  ```
- **Response**: `NavigateResponse` with `"action": "navigate_response"`, `"status": "ok"` or `"error"`.

### 2. `geturl`
- **Action**: Inspects the current primary document location (`window.location.href`).
- **Payload**:
  ```json
  {
    "action": "geturl"
  }
  ```
- **Response**: `URLResponse` with `"action": "geturl_response"`, `"url": "https://example.org"`.

### 3. `getscreenshot`
- **Action**: Captures the active viewport and resizes it to fit within **max 800x600 pixels** (preserving aspect ratio) using Lanczos downscaling.
- **Payload**:
  ```json
  {
    "action": "getscreenshot",
    "format": "jpeg",
    "quality": 85
  }
  ```
- **Response**: Transmitted as a binary `event.TypeFile` with filename `screenshot_<timestamp>.jpg` and MIME type `image/jpeg`. If capture fails, a `ScreenshotResponse` error envelope is returned.

## Usage Example

```go
package main

import (
    "context"
    "time"

    rawclient "github.com/je4/wsbrokerclient/pkg/client"
    "github.com/je4/wsbrokerdisplay/pkg/browser"
    "github.com/je4/wsbrokerdisplay/pkg/display"
)

func main() {
    // 1. Initialize WSBroker client
    rawCfg := rawclient.DefaultConfig()
    rawClient, _ := rawclient.New(rawCfg,
        rawclient.WithEndpoint("https://localhost:8765"),
        rawclient.WithClientName("display01"),
        rawclient.WithAutoReconnect(true),
        rawclient.WithLogger(logger),
    )

    // 2. Initialize browser controller
    browserCtrl := browser.New(browserCfg, logger)

    // 3. Instantiate and start display coordinator directly with rawClient
    dispCtrl := display.NewController(
        rawClient,
        browserCtrl,
        logger,
        display.WithTimeout(20*time.Second),
    )
    dispCtrl.Start()
    defer dispCtrl.Stop()

    // 4. Connect broker client
    _ = rawClient.Connect(context.Background())
    defer rawClient.Close()
}
```
